# Videos

The video API is asynchronous. You submit a job, the gateway dispatches it to a video generation provider, and you poll for completion. This page describes the lifecycle; the Mintlify reference renders the exact request and response schema from `openapi/openapi.yaml`.

## Endpoints

<CardGroup cols={2}>
  <Card title="POST /v1/videos/generations" icon="film" href="/api-reference/videos/create">

  </Card>
  <Card title="GET /v1/videos/generations/{id}" icon="circle-check" href="/api-reference/videos/get">
    Poll a job. Returns the current status, the generated asset URL when ready, or an error.
  </Card>
  <Card title="DELETE /v1/videos/generations/{id}" icon="trash" href="/api-reference/videos/delete">

  </Card>

## How an async job works

<Steps>
  <Step title="Submit">
    `POST /v1/videos/generations` with the model, prompt, and any input assets. The response is immediate and includes a `job_id`.
  </Step>
  <Step title="Poll">
    `GET /v1/videos/generations/{job_id}` returns a `status` of `queued`, `running`, `succeeded`, or `failed`. Poll every 5-10 seconds while the job runs.
  </Step>
  <Step title="Download">
    On `succeeded`, the response includes a hosted `url` for the generated video. Download it before the asset expires.
  </Step>
  <Step title="Handle failure">
    On `failed`, the response carries an `error` object with a stable `code`. Common failures include content policy violations and upstream timeouts.
  </Step>
</Steps>

<Info>
  Some video providers also support webhook callbacks. When configured, the gateway POSTs the same status payload to your endpoint as soon as the job finishes, so your application does not have to poll.
</Info>

## Minimal example

```bash
curl -X POST https://api.infinityblue.com/v1/videos/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sora-1.0",
    "prompt": "A drone shot over a misty forest at dawn",
    "duration": 5,
    "aspect_ratio": "16:9"
  }'
```

The immediate response:

```json
{
  "id": "videojob_01HXYZ...",
  "object": "video.generation.job",
  "status": "queued",
  "created_at": 1717430000
}
```

A few seconds later, the job is ready:

```json
{
  "id": "videojob_01HXYZ...",
  "status": "succeeded",
  "url": "https://cdn.infinityblue.com/vid/abc123.mp4",
  "duration": 5,
  "expires_at": 1717516400
}
```

## Cost and quotas

Video jobs are billed per second of generated footage. Polling does not incur cost, but long-running jobs do, so cancel queued jobs you no longer need. Rate limits are tighter than for chat — check the `x-ratelimit-remaining-videos` response header.

<Warning>
  Video generation can take 1-10 minutes depending on duration, resolution, and upstream load. Build your UI around the async lifecycle rather than blocking on the request.
</Warning>
