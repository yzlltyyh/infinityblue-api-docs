# Images 图片生成

AI 图像生成和编辑接口，支持多种模型格式（OpenAI DALL-E、千问、Nano Banana 等）。

<Card title="Endpoints" icon="code">
  - [POST /v1/images/generations](/api-reference/images/create-image) — 创建图片
  - [POST /v1/images/edits](/api-reference/images/edit-image) — 编辑图片
</Card>

<Note>
  详细 Schema 请参考 [English API Reference](/api-reference/images)。
</Note>

## 支持的模型

`gpt-image-1`、`dall-e-3`、`flux-pro-1.1`、`sd-3.5-large`、`qwen-image`

## 中文文字渲染

需要中文文字渲染时，推荐 `qwen-image`（在中文文字渲染上表现最好）。
