# InfinityBlue API 介绍

InfinityBlue API 是一个 **OpenAI 兼容的统一 AI 模型网关**，将主流大模型聚合在同一个端点下。只需修改 `base_url`，任何面向 OpenAI 的 SDK、框架或教程均可直接复用，无需维护多套 Key 或适配不同协议。

## 支持的模型

### 对话模型

| 系列 | 模型 ID |
|---|---|
| **OpenAI GPT** | `gpt-5.4`（旗舰）、`gpt-5.4-mini`（高性价比）、`gpt-5.5`、`gpt-5.3-codex`（代码专长） |
| **Google Gemini** | `gemini-3.1-pro-preview`、`gemini-2.5-pro`、`gemini-2.5-flash`、`gemini-3-flash-preview` |
| **DeepSeek** | `deepseek-v4-pro`、`deepseek-v4-flash` |

### 图像模型

`gpt-image-2`、`nanobanana`、`nanobanana_pro`、`nanobanana_2`

### 视频模型

`doubao-seedance-2-0-260128`、`veo_3_1`、`kling-v2-5-turbo`

## 接入方式

所有请求统一发往：

```
https://api.getinfinityblue.com/v1
```

鉴权方式与 OpenAI 完全一致——`Authorization: Bearer YOUR_API_KEY`。使用 OpenAI Python / JS SDK 只需改一个参数：

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_API_KEY",
    base_url="https://api.getinfinityblue.com/v1",
)

response = client.chat.completions.create(
    model="gpt-5.4",
    messages=[{"role": "user", "content": "你好"}],
)
```
