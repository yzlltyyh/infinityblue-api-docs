# Embeddings 向量化

文本向量化接口，用于语义搜索、RAG、聚类、分类等任务。

<Card title="Endpoints" icon="code">
  - [POST /v1/embeddings](/api-reference/embeddings/create-embedding) — 创建文本向量
</Card>

<Note>
  详细 Schema 请参考 [English API Reference](/api-reference/embeddings)。
</Note>

## 推荐的模型

| 模型 | 维度 | 适用场景 |
|---|---|---|
| `text-embedding-3-large` | 3072 | 最高质量 |
| `text-embedding-3-small` | 1536 | 性价比 |
| `voyage-3-large` | 1024 | 检索最佳 |
