# Images

The image API exposes OpenAI-compatible generation and editing endpoints. Use it to synthesize images from text prompts, transform existing images with instructions, or produce multiple variations from a single seed. The interactive reference below is generated from `openapi/openapi.yaml`.

## Endpoints

<CardGroup cols={2}>
  <Card title="POST /v1/images/generations" icon="sparkles" href="/api-reference/images/create">
    Generate one or more images from a text prompt. Returns URLs, base64 data, or both depending on `response_format`.
  </Card>
  <Card title="POST /v1/images/edits" icon="pen-to-square" href="/api-reference/images/edit">
    Edit an existing image. Provide one or more input images and a text prompt that describes the change.
  </Card>
  <Card title="POST /v1/images/variations" icon="shuffle" href="/api-reference/images/variation">
    Produce variations of a base image. Useful for exploring alternative compositions while preserving style.
  </Card>
  <Card title="GET /v1/images/{id}" icon="magnifying-glass" href="/api-reference/images/get">
    Retrieve a previously generated image by its ID, including the original prompt and metadata.
  </Card>
</CardGroup>

## When to use this API

- Marketing and creative assets generated from a brief.
- Concept art and storyboards for design sprints.
- Cover images, hero illustrations, and social cards.
- Product photography variations without re-shooting.

## Minimal example

```bash
curl https://api.infinityblue.com/v1/images/generations \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-image-1",
    "prompt": "A flat illustration of a lighthouse on a calm sea at sunrise",
    "size": "1024x1024",
    "n": 1
  }'
```

The response includes one or more entries in a `data` array. Each entry carries either a hosted `url` or a `b64_json` payload, depending on the `response_format`.

```json
{
  "created": 1717430000,
  "data": [
    {"url": "https://cdn.infinityblue.com/img/abc123.png", "revised_prompt": "..."}
  ]
}
```

## Choosing parameters

<CardGroup cols={3}>
  <Card title="size" icon="ruler">
    Square (`1024x1024`), landscape (`1536x1024`), or portrait (`1024x1536`). Match the aspect ratio to the destination.
  </Card>
  <Card title="n" icon="copy">
    How many independent images to produce. Higher counts consume more credits but let you pick the strongest result.
  </Card>
  <Card title="quality" icon="gauge-high">
    `low`, `medium`, or `high`. Higher quality takes longer and costs more.
  </Card>
</CardGroup>

<Warning>
  Generated images are subject to the upstream provider's content policy. Prompts that violate it return a `400 content_policy_violation` error rather than a placeholder image.
</Warning>
