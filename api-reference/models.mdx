# Models

The models endpoint exposes the catalog of models the gateway can route to. It returns the same identifiers you pass to other endpoints in their `model` field, plus metadata about the provider, capabilities, and deprecation status. The interactive reference below is generated from `openapi/openapi.yaml`.

## Endpoints

<CardGroup cols={2}>
  <Card title="GET /v1/models" icon="list" href="/api-reference/models/list">
    List every model available to your account. Supports filtering by capability and provider.
  </Card>
  <Card title="GET /v1/models/{id}" icon="circle-info" href="/api-reference/models/get">

  </Card>

## Why query the catalog

- Discover the current set of supported models without hardcoding names in your application.
- Detect deprecations early by checking the `status` field on each entry.
- Power a model picker UI by rendering the catalog at runtime.
- Verify that a model is available on your account before you send a request.

## Minimal example

```bash
curl https://api.infinityblue.com/v1/models \
  -H "Authorization: Bearer YOUR_API_KEY"
```

The response is a paginated list of model descriptors:

```json
{
  "object": "list",
  "data": [
    {
      "id": "gpt-4o",
      "object": "model",
      "created": 1716000000,
      "owned_by": "openai",
      "capabilities": ["chat", "vision", "tools", "streaming", "json"],
      "context_window": 128000,
      "status": "active"
    },
    {
      "id": "text-embedding-3-large",
      "object": "model",
      "created": 1707000000,
      "owned_by": "openai",
      "capabilities": ["embeddings"],
      "context_window": 8192,
      "status": "active"
    }
  ]
}
```

## Model lifecycle

<CardGroup cols={3}>
  <Card title="active" icon="circle-check">
    Available for production use. No deprecation notice.
  </Card>
  <Card title="deprecated" icon="circle-exclamation">
    Still served, but will be removed on a published date. Migrate before that date.
  </Card>
  <Card title="retired" icon="circle-xmark">
    No longer served. Requests to retired models return `404 model_not_found`.
  </Card>
</CardGroup>

<Info>
  When a model is deprecated, the gateway may automatically alias requests to its successor. The `replaced_by` field on the model descriptor names the recommended migration target.
</Info>

## Capabilities

The `capabilities` array is a coarse checklist. Use it to filter the catalog when building a model picker. Common values include `chat`, `vision`, `tools`, `streaming`, `json`, `reasoning`, `embeddings`, `audio`, `images`, and `videos`.

```bash
curl "https://api.infinityblue.com/v1/models?capability=vision" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
