# Audio 音频

语音识别（STT）、语音合成（TTS）和音乐生成接口。

<Card title="Endpoints" icon="code">
  - [POST /v1/audio/transcriptions](/api-reference/audio/create-transcription) — 语音转文字
  - [POST /v1/audio/speech](/api-reference/audio/create-speech) — 文字转语音
  - [POST /v1/audio/music](/api-reference/audio/create-music) — 音乐生成（实验性）
</Card>
