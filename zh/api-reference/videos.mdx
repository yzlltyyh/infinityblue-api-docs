# Videos 视频生成

AI 视频生成接口。**所有视频生成都是异步任务**：提交任务后获得 `task_id`，然后轮询或注册 webhook 接收结果。

<Card title="Endpoints" icon="code">
  - [POST /v1/videos/generations](/api-reference/videos/create-video) — 创建视频任务
  - [GET /v1/videos/tasks/{id}](/api-reference/videos/get-video-task) — 查询任务状态
</Card>

<Note>
  详细 Schema 请参考 [English API Reference](/api-reference/videos)。
</Note>

## 支持的模型

`kling-1.6-pro`（性价比高，5-10 秒视频）、`sora-1.0-turbo`（顶级质量，1080p，20 秒）、`veo-2`（4K）

## 任务生命周期

```
pending → processing → succeeded
                  ↘ failed
                  ↘ cancelled
```

视频生成通常 30s-3min。建议用 webhook 而不是轮询。
