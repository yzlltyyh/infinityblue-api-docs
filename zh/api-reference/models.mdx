## 模型分类

按能力分：
- **Chat**: `gpt-4o`、`claude-3.5-sonnet`、`gemini-2.0-flash` 等
- **Image**: `gpt-image-1`、`dall-e-3`、`flux-pro` 等
- **Video**: `sora-1.0-turbo`、`kling-1.6-pro`、`veo-2` 等
- **Audio**: `whisper-1`、`tts-1` 等
- **Embedding**: `text-embedding-3-large` 等
- **Rerank**: `rerank-3.5` 等
